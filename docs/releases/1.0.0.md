# Promecapt 1.0.0

Promecapt is an MIT-licensed, open-source alternative to proprietary screenshot tools for macOS: screenshots, editable annotations, floating image / GIF pins, region OCR and GIF recording.

- A shared capture-frame icon for the app and menu bar.
- Korean, English, Japanese and Simplified Chinese UI, with a language selector.
- Automatic window / element targeting, compact annotation toolbar and customizable shortcuts.
- Capture history with full display context for new captures.
- Configurable GIF recording with a visible region; preview, copy, animated pin and save.

## Download and setup

Requires macOS 13+. Choose `arm64` for Apple Silicon or `x86_64` for Intel. Open the DMG and drag **Promecapt.app** onto **Applications**, then eject the disk image and launch the installed app. ZIP downloads are also available. Enable Screen Recording for capture and Accessibility for element detection and enhanced global shortcuts.

**These packages are ad-hoc signed, not Developer ID signed or Apple-notarized.** macOS may block opening them. A paid Apple Developer account is not required to build and run locally. Follow the [local installation guide](https://github.com/PROMLEE/promecapt/blob/main/docs/INSTALL.md), or Apple's per-app opening instructions for a trusted download. Do not disable system security globally. Automatic updates are not included.

History stores full display snapshots locally as well as the selected image. Current OCR recognition languages are Korean and English. GIF recording stays on one display and does not include audio or Promecapt windows; GIF editing is not included.

SHA-256 files accompany the DMG and ZIP downloads. See the multilingual README for detailed usage, permissions and storage behavior.
