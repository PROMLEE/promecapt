# Promecapt 1.0.0

First public release of Promecapt: a native macOS app for screenshots, editable annotations, floating image / GIF pins, region OCR and GIF recording.

- A shared capture-frame icon for the app and menu bar.
- Korean, English, Japanese and Simplified Chinese UI, with a language selector.
- Automatic window / element targeting, compact annotation toolbar and customizable shortcuts.
- Capture history with full display context for new captures.
- Configurable GIF recording with a visible region; preview, copy, animated pin and save.
- Existing Promepaste preferences and libraries remain compatible.

## Download and setup

Requires macOS 13+. Choose `arm64` for Apple Silicon or `x86_64` for Intel. Unzip and move **Promecapt.app** to Applications. Enable Screen Recording for capture and Accessibility for element detection and enhanced global shortcuts.

**These packages are ad-hoc signed, not Developer ID signed or Apple-notarized.** macOS may block opening them. Review the source / build locally or follow Apple's per-app instructions for a trusted app. Do not disable system security globally. Automatic updates are not included.

History stores full display snapshots locally as well as the selected image. Current OCR recognition languages are Korean and English. GIF recording stays on one display and does not include audio or Promecapt windows; GIF editing is not included.

SHA-256 files accompany the ZIP downloads. See the multilingual README for detailed usage, permissions and storage behavior.
