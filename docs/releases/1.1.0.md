# Promecapt 1.1.0

- **Manual updates:** menu bar → Check for Updates…, or Settings → About.
- **Automatic updates (optional):** download, install and relaunch; off by default. Work in progress delays installation.
- **About:** installed version, build, revision, CPU, OS, latest version and last check time.
- Signed update feeds and archives for Apple Silicon and Intel.

**Upgrading from 1.0.0:** install this version manually once using the DMG. Later releases can update in the app.

The app remains ad-hoc signed and not Apple-notarized. First launch may require macOS's per-app approval, and screen permissions may need refreshing after replacement. [Installation guide](https://github.com/PROMLEE/promecapt/blob/main/docs/INSTALL.md).
