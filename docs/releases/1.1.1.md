# Promecapt 1.1.1

- Brighter, opaque annotation toolbar with clearer icons, text and selected tools.
- Newly drawn annotations are selected immediately. Turn this off in Settings → Capture for continuous drawing.
- Keep the color panel above capture windows. Cancel shortcut recording when clicking outside the recorder.
- Startup permission guide with Screen Recording / Accessibility request buttons and live status.
- Offer installation into Applications when opening a ZIP app elsewhere.
- Startup pin restoration defaults to off; existing stored pins and explicit preferences are preserved.
- Updated installation guide with real macOS screenshots; checksum comparison is optional.

**Testing:** Apple Silicon and Intel CI builds and automated tests run before publication. Native visual acceptance of these UI changes is pending; this release is being published for user testing.

**Permissions:** this release remains ad-hoc signed and not Apple-notarized. Updating may require refreshing Promecapt’s Screen Recording / Accessibility permissions. The experimental self-signed certificate is not used in this release. [Install guide](https://github.com/PROMLEE/promecapt/blob/main/docs/INSTALL.md).
