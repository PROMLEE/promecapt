# Promecapt 1.1.10

- Copy OCR text with Command-C and close the result window after a successful copy. Copy selected text, or all text when nothing is selected; the Copy all button also closes the window.
- Keep GIF recording controls on the recording display, including monitors with negative or vertically arranged coordinates.

GIF recording still does not support live annotations or frame editing. Playback, copy, pin and save remain available after recording.

**Validation:** Local checks cover OCR Unicode selection, whole-copy, empty-result clipboard preservation and Command-C routing, plus control placement for negative and vertically arranged display coordinates. Live multi-monitor recording has not been verified. The existing production signing certificate is retained; Apple notarization is not provided.

## 한국어

- OCR 결과에서 ⌘C로 선택한 텍스트를, 선택이 없으면 전체를 복사한 뒤 창을 닫습니다. 전체 복사 버튼도 복사 후 닫힙니다.
- GIF 녹화 정지창을 녹화 영역이 있는 모니터 안에 배치하도록 수정했습니다.

GIF 녹화 중 주석·프레임 편집은 지원하지 않습니다. 녹화 후 재생·복사·고정·저장은 가능합니다.

**검증:** OCR 선택·전체 복사, 빈 결과의 클립보드 유지, ⌘C 처리와 좌우·상하 모니터 좌표의 정지창 배치를 로컬 검사했습니다. 실제 다중 모니터 녹화 검증은 아직입니다. 기존 고정 인증서를 유지하며 Apple 공증은 제공하지 않습니다.
