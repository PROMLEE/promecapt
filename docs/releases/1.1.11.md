# Promecapt 1.1.11

Open the project's [GitHub Sponsors page](https://github.com/sponsors/PROMLEE) from **Support Development…** in the menu bar or **Settings → About**. Promecapt is free to use and sponsorship is optional.

Official builds use the existing signing certificate. Apple notarization is not provided.

## 한국어

메뉴 막대 또는 **설정 → 정보**의 **개발 후원…**에서 [GitHub Sponsors 페이지](https://github.com/sponsors/PROMLEE)를 열 수 있습니다. Promecapt는 무료이며 후원은 선택입니다.

공식 빌드는 기존 고정 서명 인증서를 사용합니다. Apple 공증은 제공하지 않습니다.
