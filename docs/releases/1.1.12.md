# Promecapt 1.1.12

- **Damaged library recovery:** if the capture history or pin index file is damaged, Promecapt keeps the damaged file as `*.corrupt-<time>.json` and rebuilds the list from the saved images instead of failing to start or dropping pins.
- **Previous-session pins:** when pins are not restored at startup, the menu bar shows **Restore previous pins** and **Delete previous pins…** so earlier pins no longer accumulate unseen.
- **Faster history:** captures are saved in the background, and the history menu uses cached, aspect-correct thumbnails.
- **Lighter pin saving:** moving or resizing a pin saves only its position.
- **Permissions:** only Screen Recording is required at startup. Accessibility is offered once and remains available under **Permissions…**.

Official builds use the existing signing certificate. Apple notarization is not provided.

## 한국어

- **보관함 손상 복구:** 캡처 기록이나 고정 이미지 목록 파일이 손상되면 손상된 파일을 `*.corrupt-<시각>.json`으로 남기고 저장된 이미지에서 목록을 다시 만듭니다. 앱이 열리지 않거나 고정 이미지가 사라지지 않습니다.
- **이전 세션 고정 이미지:** 시작할 때 고정 이미지를 복원하지 않도록 설정한 경우 메뉴 막대에 **이전 고정 이미지 복원**과 **이전 고정 이미지 지우기…**가 표시됩니다.
- **더 빠른 캡처 기록:** 캡처 기록을 백그라운드에서 저장하고, 기록 메뉴의 썸네일은 비율을 유지해 한 번만 만듭니다.
- **가벼워진 고정 이미지 저장:** 고정 이미지를 옮기거나 크기를 바꾸면 위치만 저장합니다.
- **권한:** 시작할 때는 화면 녹화 권한만 요구합니다. 손쉬운 사용 권한은 한 번만 안내하며 **권한 설정…**에서 언제든 열 수 있습니다.

공식 빌드는 기존 고정 서명 인증서를 사용합니다. Apple 공증은 제공하지 않습니다.
