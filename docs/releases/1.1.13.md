# Promecapt 1.1.13

- **Pin size on Retina displays:** pinned images from the clipboard, history or files now open at their on-screen size instead of twice as large, and **Actual size** returns them to that size.
- **Menu wording:** the English menu now reads **Quit Promecapt**.

Official builds use the existing signing certificate. Apple notarization is not provided.

## 한국어

- **Retina 화면의 고정 이미지 크기:** 클립보드·캡처 기록·파일에서 고정한 이미지가 두 배로 커지지 않고 화면 크기 그대로 열리며, **원본 크기**도 이 크기로 돌아갑니다.
- **메뉴 문구:** 영어 메뉴가 **Quit Promecapt**로 표시됩니다.

공식 빌드는 기존 고정 서명 인증서를 사용합니다. Apple 공증은 제공하지 않습니다.
