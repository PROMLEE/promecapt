# Promecapt 1.1.2

- Reuse a persistent code-signing certificate across official releases.
- Remove duplicate Settings menu entries; Help opens the usage guide.
- Move settings explanations into ? help popovers with sentence-by-sentence line breaks.

**Permission migration:** this first update from ad-hoc signing may require one final removal and re-addition of Screen Recording and Accessibility permissions. Later releases reuse the same identity. This is self-signing, not Apple notarization; Open Anyway may still be necessary.
