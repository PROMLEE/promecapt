# Promecapt 1.1.3

- Replace custom annotation buttons with native macOS controls and SF Symbols. Fix overlap across translations and macOS control sizes.
- Show color and numeric options only when applicable; show redaction styles only for redaction, and hide strength for opaque black boxes.
- Change width and redaction strength by one unit per wheel detent. Accumulate precise trackpad motion and ignore momentum after release.
- Use finer pin zoom (3%) and Ctrl-wheel opacity (two percentage points) per normalized step.
- Keep the same code-signing certificate as 1.1.2; no signing identity rotation.

**Validation:** Korean, English, Japanese and Simplified Chinese in light/dark AppKit layouts, every annotation tool, selected-object options, OCR/history states, a 900pt editor, and accelerated/precise scroll inputs. Physical mouse/trackpad and live capture interaction remain pending; the owner requested this release for hands-on verification. Apple notarization is not available. Users upgrading from before 1.1.2 may still need the one-time permission migration.

## 한국어

- 도구창을 macOS 기본 컨트롤과 SF Symbols로 바꾸고 번역·OS별 크기 차이로 생기는 겹침을 수정했습니다.
- 선택한 도구·주석에 필요한 색상·두께만 표시합니다. 가리기 방식은 가리기 도구에서만, 블랙박스는 세기 조절 없이 표시합니다.
- 마우스 휠 한 칸은 두께·가리기 세기 ±1로 처리합니다. 트랙패드는 이동량을 모아 조절하고 손을 뗀 뒤 관성 입력은 무시합니다.
- 고정 이미지 확대·축소는 한 단계 3%, Ctrl+휠 투명도는 2%p로 세밀하게 조절합니다.
- 1.1.2와 동일한 고정 인증서로 서명합니다.

**검증 범위:** 네 언어·라이트/다크의 실제 AppKit 배치와 렌더링, 모든 도구의 옵션 표시, 기존 주석 선택, OCR·기록 안내, 최소 폭 편집창, 스크롤 입력을 검사했습니다. 실제 캡처 화면의 클릭·물리 마우스·트랙패드 조작은 아직 검증하지 못했으며, 사용자 요청에 따라 직접 설치해 확인할 수 있도록 배포합니다. Apple 공증은 없으며, 1.1.2 이전 버전에서 넘어오면 최초 권한 재등록이 필요할 수 있습니다.
