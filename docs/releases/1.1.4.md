# Promecapt 1.1.4

- Keep icons inside flexible-height native buttons, with white enabled symbols in dark mode even when the capture window is not key.
- Remove unnecessary toolbar padding and the second-row spacer. Width follows visible options; ordinary capture is about 360pt instead of 560pt.
- Add an explicit **Apply** button (Return) to the color panel to finish color selection and return to editing.
- Use the same annotation buttons in the standalone editor.
- Reuse the existing production signing certificate.

**Validation:** four-language light/dark AppKit layout and rendering checks, contextual states, toolbar resize/geometry, actual white symbol pixels, and color confirmation footer geometry. Physical capture/color-panel interaction still requires user verification; this release continues the owner's hands-on feedback cycle. The app is not Apple-notarized.

## 한국어

- 버튼의 실제 높이에 맞춰 아이콘을 안쪽에 배치하고, 다크 모드의 활성 아이콘을 흰색으로 표시합니다.
- 도구창 위아래 여백과 둘째 줄 중간의 빈 공간을 줄였습니다. 보이는 옵션에 맞춰 폭이 변하며 일반 캡처는 약 560pt에서 360pt로 줄었습니다.
- 색상창에 **확인** 버튼과 Enter 키 동작을 추가해 색상 선택을 마치고 편집으로 돌아올 수 있습니다.
- 별도 편집창에도 같은 아이콘 버튼을 적용했습니다.
- 기존 고정 인증서를 그대로 사용합니다.

**검증 범위:** 네 언어·라이트/다크의 AppKit 배치와 렌더링, 도구별 옵션과 폭 변경, 겹침·잘림 검사, 실제 흰색 아이콘 픽셀, 색상 확인 버튼 배치를 검사했습니다. 실제 캡처 화면과 색상창의 클릭 조작은 사용자 확인이 남아 있습니다. Apple 공증은 없습니다.
