# Promecapt 1.1.5

- Keep the drawing tool active after creating an annotation. Automatic selection applies to the new object; adjust its handles or draw the next annotation on empty space without choosing the tool again.
- Preserve the active tool through undo/redo and OCR cancellation. Space no longer switches to region adjustment after a capture area is selected.
- Fix incorrect toolbar help after controls move or hide: resolve the live button under the pointer, cancel outdated delayed help and show only one tooltip system.
- Reduce button spacing, retaining native popup/color-well clearance.
- Keep the existing production signing certificate.

**Validation:** AppKit stroke/resize input sequences, annotation preferences, all-tool live help hit testing, four languages, light/dark layout/rendering and both CPU builds. Physical capture/hover interactions still need owner verification; this release continues the owner's hands-on feedback cycle. The app is not Apple-notarized.

## 한국어

- 주석을 작성한 뒤 자동 선택하더라도 그리기 도구를 유지합니다. 방금 그린 주석을 바로 수정하거나 빈 곳에서 다음 주석을 이어서 그릴 수 있습니다.
- 실행 취소·다시 실행·OCR 취소 뒤에도 도구를 유지합니다. 캡처 영역을 정한 뒤 Space를 눌러도 영역 조절로 전환되지 않습니다.
- 도구창 크기나 옵션 표시가 바뀌어도 현재 마우스 아래 버튼의 툴팁을 표시합니다. 이전 위치에 예약된 설명과 중복 기본 툴팁을 제거했습니다.
- 버튼 간격을 조금 줄이되 가리기 메뉴·색상 버튼의 테두리 여유는 유지했습니다.
- 기존 고정 인증서를 그대로 사용합니다.

**검증 범위:** 연속 도형 작성·핸들 수정 입력, 자동 선택 설정, 도구별 툴팁 대상, 네 언어·라이트/다크 배치를 검사합니다. 실제 캡처와 마우스 호버 조작은 사용자 확인이 남아 있습니다. Apple 공증은 없습니다.
