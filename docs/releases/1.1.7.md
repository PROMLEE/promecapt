# Promecapt 1.1.7

- Replace duplicate capture dimensions with one size readout and a draggable shortcut card; H collapses or expands the card.
- Use Shift-drag for a square and Command-drag to preserve the aspect ratio at the start of a region adjustment.
- Add automatic target detail settings: Fine, Balanced (default), Prefer large areas and Windows only.
- Read the entire selected capture with OCR or O; use Option-click or Shift-O for a smaller OCR region.

The target detail setting is under Settings → Capture. Balanced skips tiny icons and text regions; the other levels change geometric filtering rather than adding recognition delay. Tab / Shift-Tab cycles the remaining targets. Command-drag uses 1:1 when a new region has no previous ratio. Size appears beside the region only while dragging, then in the toolbar.

**Validation:** Local AppKit input/layout checks across four languages and light/dark appearances, all eight aspect-preserving resize handles, screen edges and tiny full-region OCR extraction. Live Mac checks covered the shortcut card, full OCR with recognized output, Option-click/Shift-O partial OCR, cancellation and OCR button state. Physical modifier-held drag and browser detection feel still need owner verification. The existing production signing certificate is retained; Apple notarization is not provided.

## 한국어

- 크기 중복 표시를 없애고 이동 가능한 단축키 안내 패널을 추가했습니다. H로 접고 펼칠 수 있습니다.
- Shift 드래그는 정사각형, ⌘ 드래그는 영역 조절 시작 시 비율을 유지합니다.
- 자동 영역 인식 범위를 세밀하게·균형(기본)·큰 영역 위주·창만으로 설정할 수 있습니다.
- OCR 버튼이나 O로 캡처 전체를 바로 읽습니다. ⌥클릭 또는 Shift+O는 부분 OCR입니다.

설정 → 캡처에서 인식 범위를 선택합니다. 균형은 작은 아이콘·글자 영역을 건너뜁니다. 인식 지연을 추가하는 방식이 아니라 영역 크기를 기준으로 필터링합니다. Tab / Shift+Tab으로 남은 상위·하위 영역을 선택할 수 있습니다. 기존 비율이 없는 새 영역의 ⌘ 드래그는 1:1로 시작합니다. 크기는 드래그 중 영역 옆에, 선택 후 도구창에 한 번만 표시합니다.

**검증 범위:** 네 언어 라이트/다크 배치·입력, 8개 비율 유지 핸들·화면 경계·작은 캡처 전체 OCR 추출을 자동 검사했습니다. 실제 Mac에서는 단축키 안내, 텍스트 인식 결과, 전체/부분 OCR 전환·취소·버튼 상태를 확인했습니다. 보조키를 누른 실제 드래그와 브라우저 인식 감도는 사용자 확인이 남아 있습니다. 기존 고정 서명 인증서를 유지하며 Apple 공증은 제공하지 않습니다.
