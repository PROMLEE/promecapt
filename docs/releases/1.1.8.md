# Promecapt 1.1.8

- Use one adjacent, borderless toolbar row with monochrome selection indicators.
- Enter capture width and height directly in pixels; oversized values stay within the display.
- Choose visible buttons in Settings → Tools. Hidden actions remain available in All tools (…).
- Make the shortcut card translucent while keeping text opaque, and document how to open the separate image editor.

Native color and stepper alignment bounds are normalized across macOS versions to avoid overlaps without adding toolbar gaps.

Undo, redo and close buttons are hidden by default; their shortcuts remain available. The separate editor follows shared tool visibility preferences and keeps crop/rotate/flip controls. To open it, choose Open image file… from the Promecapt menu bar menu and select an image. Captures are edited in place.

**Validation:** Four-language light/dark AppKit layout and input checks, zero-gap editor controls, rendered transparency, live button visibility, hidden-tool access, invalid pixel input and Retina geometry. Live capture checks confirmed translucent help, hiding/recovering the pencil and resizing from 500 × 300 to 640 × 480. Separate-editor rendering was verified offscreen; live file-chooser navigation was blocked by the automation tool. The existing production signing certificate is retained; Apple notarization is not provided.

실행 취소·다시 실행·닫기 버튼은 기본적으로 숨기며 단축키는 그대로 사용할 수 있습니다. 별도 편집창도 공통 표시 설정을 따릅니다. 편집창은 메뉴 막대 Promecapt → 이미지 파일 열기…에서 이미지를 선택하면 열립니다. 캡처 화면은 그 자리에서 편집합니다.

**검증:** 네 언어 라이트/다크 배치·입력, 편집창 버튼 간격, 실제 렌더링 투명도, 버튼 숨김·기능 접근, 잘못된 크기 입력·Retina 좌표를 검사했습니다. 실제 캡처에서는 반투명 안내, 펜 숨김·메뉴 접근, 500 × 300에서 640 × 480으로 크기 변경을 확인했습니다. 별도 편집창 배치는 오프스크린으로 확인했으며, 실제 파일 선택 단계는 자동화 도구 오류로 검증이 남았습니다. 기존 고정 인증서를 유지하며 Apple 공증은 제공하지 않습니다.
