## 한국어

- 설정 → 도구에서 행을 드래그하거나 위로·아래로 버튼으로 도구 순서를 바꿀 수 있습니다.
- 캡처 크기 입력의 상하 정렬을 맞추고 영역 조절 도구에서만 표시합니다.
- 도구 버튼은 첫 줄에 두고 색상·두께·가리기 옵션은 필요할 때만 두 번째 줄에 표시합니다.
- 마지막 캡처 도구 기억 옵션을 추가했습니다. 켜면 다음 캡처에서도 마지막으로 직접 고른 도구를 사용합니다. 기본값은 꺼짐입니다.

순서·표시 변경은 즉시 적용되고 저장됩니다. 숨긴 기능은 모든 도구(…) 메뉴에 남습니다. 별도 이미지 편집창도 공통 순서와 옵션 배치를 따릅니다. 선택한 주석이 없는 주석 선택 도구에서는 두 번째 줄이 접힙니다. 기억 옵션은 설정 → 도구에 있으며 자동 주석 선택이나 별도 편집창·고정 이미지의 도구 변경은 기억할 도구를 바꾸지 않습니다.

**검증:** 네 언어 라이트/다크 배치·렌더링 정렬, 순서 저장, 숨긴 기능 접근, 옵션 행 표시, 연속 캡처의 도구 복원을 검사했습니다. 실제 Mac에서 이동 버튼·드래그 재정렬, 영역 모드 크기 입력, 주석 선택의 한 줄 접힘, 사각형 옵션 두 번째 줄, 다음 캡처의 사각형 복원을 확인했습니다. 검증 중 바꾼 설정은 복원했습니다. 기존 고정 인증서를 유지하며 Apple 공증은 제공하지 않습니다.
