# Promecapt

> An MIT-licensed, open-source alternative to proprietary macOS screenshot tools: capture, editable annotations, floating image / GIF pins, region OCR and GIF recording.

Canonical index: https://raw.githubusercontent.com/PROMLEE/promecapt/main/llms.txt

Current public release: 1.1.8. macOS 13+, Apple Silicon and Intel. Build locally with free Apple command-line tools; no paid Apple Developer account is required. Official packages reuse a persistent self-signed certificate, not an Apple Developer ID or notarization. The initial transition may require a one-time permission refresh. Managed Mac policies still apply.

Processing is local. History includes full display snapshots. UI languages: Korean, English, Japanese and Simplified Chinese. OCR recognition: Korean and English. Manual and opt-in automatic updates use signed Sparkle feeds and archives. Version 1.0.0 requires one manual bootstrap installation. GIF frame editing is not implemented.
